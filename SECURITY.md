# Security policy

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/zohartito/camera-autopilot/security/advisories/new).
Private reporting is enabled for this repository. Please do not open a public
issue with exploit details before the report has been reviewed.

Include the affected commit or version, a description of the impact, and the
smallest reproduction you can provide. Remove API tokens, camera serials,
network addresses and private photos from logs or attachments.

Security fixes target the current `main` branch. Older snapshots and native app
builds are not maintained as separate supported release lines. Use the private
report to coordinate a fix and public disclosure with the maintainer.
