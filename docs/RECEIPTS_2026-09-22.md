# Receipts — live runs of 22–23 September 2026, and the receipt index

Step 0.1 of [SEQUENTIAL_AGENT_STACK_2026-09-27.md](SEQUENTIAL_AGENT_STACK_2026-09-27.md). This doc
does two jobs:

1. It records the live camera runs of 22–23 September, which until now existed only under the
   gitignored `artifacts/` directory and in one session transcript. Each file is listed with its
   size and SHA-256, the body that took it, the settings, and a verdict.
2. Its **Receipt index** names the evidence behind every row of
   [PROJECT_LEDGER_2026-09-27.md](PROJECT_LEDGER_2026-09-27.md) marked Finished.

**The photographs are not in git.** They are private (the owner's home, people and pets) and stay
under `artifacts/` on the owner's Mac. What is in git is enough to find them:
`python3 scripts/check_ledger_receipts.py` re-hashes every file in the SHA-256 tables below (the
22–23 Sep runs) and fails if one is missing or different. Files cited only in the Receipt index
(older receipts) are checked for existence, not content: those runs were never hashed when they
were taken. The check also fails if a Finished row has no entry in a receipt index, or if the
ledger's tally disagrees with its rows. It runs locally only; hosted CI has no `artifacts/`.
Later receipts docs (named RECEIPTS_ plus a date, in the docs folder) add their own index rows, and the check
reads all of them.

**Clocks and serials.** The A7 III's clock runs about nine hours ahead of the Mac (EXIF
`2026:09:23 04:18` for a Mac time of 22 Sep 19:25 PDT), so Mac times are quoted here. The
serial that selects a body is its **USB serial**, read by the OS (A7 III `A7III0SERIAL`, A7 II
`A7II00SERIAL`). EXIF's `InternalSerialNumber` is a different number (A7 III `<a7iii-exif-serial>`,
A7 II `<a7ii-exif-serial>`) and is listed only to tie a file to a body.

**Provenance of the run logs.** Several runs printed their results to the terminal without writing
a record. Those outputs are copied verbatim, with the transcript timestamp in a header, into
`*_run*.txt` files beside the photos. Nothing was re-run to produce them.
